📚 Learning Management System (LMS)

A full-stack Learning Management System built using the MERN stack (MongoDB, Express.js, React.js, Node.js) with Elasticsearch integration for advanced search and analytics.  
This project enables seamless management of students, teachers, and administrators with role-based authentication, course management, and progress tracking.  

🚀 Features

- 🔐 Role-based Authentication
  - Secure login and registration (Student / Teacher / Admin)
  - JWT-based authentication and authorization

- 📘 Course Management
  - Create, update, and delete courses
  - Assign teachers and manage enrollments
  - Students can enroll in and track progress

- 🎯 Student Dashboard
  - View available courses
  - Track completed modules and assignments
  - Clean and responsive UI

- 🛠️ Admin Panel
  - Manage users (teachers & students)
  - Approve/reject courses
  - Monitor platform activity

- 🔍 Elasticsearch-Powered Search
  - Fast and scalable search for courses, users, and content
  - Full-text search with filters (teacher, subject, course level)
  - Real-time indexing for smooth user experience

- 📊 Scalable APIs & Database
  - MongoDB for secure, structured storage
  - Optimized APIs for fast CRUD operations
  - Elasticsearch for analytics-ready search queries

 🏗️ Tech Stack

- Frontend: React.js, HTML5, CSS3, JavaScript (ES6+)
- Backend: Node.js, Express.js
- Database: MongoDB
- Search & Analytics: Elasticsearch
- Authentication: JWT, bcrypt
- Tools & Deployment: Git/GitHub, VS Code
